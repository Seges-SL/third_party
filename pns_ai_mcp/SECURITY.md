# Security

Report vulnerabilities **privately**: on GitHub, **Security → Report a vulnerability**, or to
PATANEGRA Soft SL via [patanegra.com](https://patanegra.com).

This module proposes writes (Safe Plan). A report that lets an unattended
client apply ORM writes, bypass the MCP key, or exfiltrate secrets is
in scope.

Do not open a public issue with a proof of concept, exploit steps, or
credentials. We will acknowledge the report and work on a fix before any
disclosure.
